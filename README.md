# KeyOverlay

Оверлей нажатий клавиш W A S D, Shift, Ctrl и Backspace для экрана.

## Установка и запуск (для пользователей)
1. Скачайте `KeyOverlay.exe`.
2. Запустите двойным кликом. Python устанавливать не нужно.

## Управление
- **ЛКМ + перетаскивание**: переместить
- **ПКМ**: меню (настройки, поверх окон, выход)
- **Ctrl + Alt + Q**: полностью закрыть программу из любого окна

## Настройки
Меню ПКМ → «Настройки». Всё меняется сразу, кнопка «Сохранить» записывает в `config.json`
рядом с exe. Раскладку клавиш можно править в блоке `keys` файла `config.json`.

## Сборка exe
Вариант 1, без установки Python: загрузить папку в GitHub, вкладка Actions, скачать артефакт `KeyOverlay`.
Вариант 2, на Windows с Python: запустить `build.bat`. Результат в `dist\KeyOverlay.exe`.

## Что программа создаёт на компьютере
Только `config.json` рядом с exe. Интернет не используется, ничего не устанавливается и не
прописывается в автозагрузку.
